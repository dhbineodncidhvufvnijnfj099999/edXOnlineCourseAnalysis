# edX 在线课程完课率漏斗分析

> 在线课程平台注册量大但完课率低，需要定位流失环节，判断运营资源该往哪里投。

## 项目背景

edX（HarvardX / MITx）公开的学习日志里，注册用户很多，但最终拿到证书的人很少。这个项目想搞清楚：

- 整体完课率到底有多低？
- 用户是在哪一步流失的？
- 哪类课程 / 哪类人群的完课率更高？
- 运营应该先优化哪个环节，投入产出比最高？

## 技术栈

`MySQL` · `Python (Pandas / Requests / BeautifulSoup)` · `Power BI` · `FastAPI`

## 数据

- **主数据**：HarvardX / MITx 公开学习日志，清洗后入库 **64.1 万行**
- **补充数据**：爬取 Coursera 平台的课程时长、语言、合作方字段，覆盖公开数据集没有的维度

## 分析思路

1. **数据清洗**：用 Python + MySQL 统一 `action` 口径，剔除注册时间超出课程有效期的异常记录，保证漏斗每一层的统计口径一致
2. **漏斗拆解**：用 `CTE + COUNT(DISTINCT user_id)` 拆「注册 → 观看 → 探索 → 获证」四层转化
3. **维度下钻**：用窗口函数按课程平台 / 国家 / 学历切片，找高转化人群特征
4. **交付**：Power BI 五维切片看板 + FastAPI 封装 3 个查询接口，业务方可自助下钻，不用每周重复取数

## 关键结论

| 指标         | 数值                                               |
| ------------ | -------------------------------------------------- |
| 整体完课率   | **3.40%**（47.65 万注册，仅 16,224 人获证）        |
| 最大流失环节 | 「观看 → 探索」转化率仅 **11.0%**，流失达 89%      |
| 平台对比     | MITx 完课率 **7.48%**，是 CS50x（0.76%）的近 10 倍 |
| 国家对比     | 西班牙用户完课率 **10.85%**，最高                  |
| 学历对比     | 硕士学历完课率 **4.52%**，高学历对应高完课         |

**给运营的建议**：

- 主攻「观看 → 探索」环节的引导改版（详情页引导、首课激励），这是投入产出比最高的环节
- 投放与推荐资源向高完课课程、高学历 / 高活跃人群倾斜
